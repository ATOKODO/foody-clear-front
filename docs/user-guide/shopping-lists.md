# Shopping lists

Shopping lists hold products you intend to buy. Their quantities do not affect stock until you convert items into an inventory. Shopping templates are reusable copies of list contents and are separate from daily planning templates.

## Create and populate a list

1. Open **Shopping lists**, select the list view and choose **Add**.
2. Name the list and create it.
3. Open **Edit**, then use **Choose** in the Add product section.
4. Select a catalog product, enter a positive quantity and choose a compatible unit.
5. Add the line. Repeat for other products.

The main detail view shows list contents read-only. Open **Edit** to change quantities, remove lines, check items or change the name.

## Check and transfer purchases

1. In the list editor, check the collected lines. **Tout cocher** checks all; **Tout decocher** unchecks all.
2. In **Envoyer vers inventory**, select the destination inventory.
3. Choose **Convertir cochees** to transfer checked lines, or **Convertir tout** to transfer the whole list.
4. Review the destination in **Inventories** after conversion.

Conversion creates the relevant stock additions and purchase accounting. Do not also add the same purchase manually to inventory. If the product lacks a usable price, reporting can show the purchase as incomplete rather than inventing a price.

Inventory must already exist. Create it in [Inventories](./inventories.md) if the destination dropdown is empty. Unit conversion follows the product definition; see [Units and nutrition](../reference/units-nutrition.md).

## Reuse a shopping template

Use **Save as template** in a list editor and give the template a name. Switch to the shopping template view to inspect or edit it.

To make a fresh list, open the template editor, enter the new list name and choose **Create la liste**. The new list gets copied contents and can be changed independently for that shopping trip.

You can also generate a recipe list from [Meal prep](./meal-prep.md). Review it against existing stock: current generation covers the full recipe requirements.

## Common distinctions

| Action | Effect |
| --- | --- |
| Add or edit a shopping line | Changes intended purchases |
| Check a line | Selects it for conversion |
| Convert to inventory | Adds actual stock and purchase events |
| Save a shopping template | Saves recurring shopping contents |
| Create a daily template | Plans food for consumption; managed in Templates |
