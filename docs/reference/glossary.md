# Glossary

| Term | Meaning |
| --- | --- |
| Product | A concrete catalog food with a package size, optional nutrition and pricing |
| Generic product | A broader product identity grouping concrete catalog products |
| Category | A product classification |
| Tag | A label that can be attached alongside other labels |
| Inventory | A named stock location |
| Normalized quantity | Quantity converted into the product's base dimension, such as g or ml |
| Product unit | One purchasable unit with the package quantity defined in the catalog |
| Portion | A named subdivision with a configured count or normalized size |
| Shopping list | Intended purchases, optionally checked and transferred into stock |
| Shopping template | Reusable shopping-list contents |
| Dish | A reusable composition of catalog product ingredients |
| Meal | A composition of dishes and/or catalog products |
| Daily template | Planned products, dishes or meals with quantities, slots and preferred times |
| Slot | A named, ordered grouping for daily entries and optional targets |
| Day set | Targets, slots and a template for one type of cycle day |
| Cycle | A fixed-duration reusable sequence of defaults and day sets |
| Assignment | A cycle applied to an inclusive range of actual dates |
| Input day | The day's recorded food and its planning context |
| Conversion | Applying planned food as actual consumption and deducting ingredient stock |
| Allocation | The quantity an entry consumed from a specific inventory |
| Restore to template | Undoing an effective conversion so its line becomes planned again |
| External entry | A meal with whole-entry macros and spending, without stock consumption |
| Actual totals | Nutrition from recorded food |
| Projected totals | Recorded nutrition plus pending planned food |
| Target source | The planning level supplying daily targets: day set, cycle or none |
| Incomplete nutrition | A required nutrition value is missing, rather than known to be zero |
| Purchase event | Accounting record created by a stock addition |
| Price version | A product price and unit effective over an interval |
| PWA | An installable browser app with a production service worker |
| Application shell | Cached interface assets; distinct from backend data or offline saves |
